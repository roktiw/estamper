---
title: Presets
description: Built-in playground and config presets.
---

The playground includes these presets:

- `standard` — balanced default.
- `minimal` — shortest readable stamp.
- `verbose` — includes dirty, branch, and build number segments.
- `games` — playful tokens for web games and canvas apps.
- `ascii` — terminal-safe output.
- `ci` — GitHub Actions oriented.
- `custom` — keep your current edits.
